# Mintlify Landing Page Clone

A pixel-inspired recreation of the **Mintlify** marketing landing page using **HTML5 and modern CSS**.  
This project focuses on layout accuracy, typography, spacing, and visual hierarchy to closely match the original design.

---

## 📌 Project Overview

This project is a static frontend implementation of the Mintlify homepage.  
It demonstrates proficiency in:

- Semantic HTML
- CSS variables and theming
- Modern UI patterns (cards, badges, gradients, CTAs)

No frameworks or libraries were used—everything is built with **vanilla HTML and CSS**.

---

## 🧩 Sections Recreated

The following sections from the original Mintlify website were recreated:

1. **Navigation Bar**
   - Logo
   - Resource links
   - Call-to-action buttons (Contact Sales, Start for Free)
   - Sticky navigation with backdrop blur

2. **Hero Section**
   - Announcement badge
   - Main headline and subheading
   - Email capture form
   - Hero illustration background

3. **Company Logos Section**
   - Grid-based layout showcasing partner and customer logos

4. **Feature Section**
   - Feature cards highlighting:
     - LLMs & MCP
     - Agent-based knowledge management
     - AI Assistant for users
   - Embedded looping videos

5. **Enterprise Features Section**
   - Enterprise-focused messaging
   - Feature cards (Partnership, Compliance)
   - Interactive banner with hover overlay
   - Enterprise customer logos

6. **Case Study / Customer Stories**
   - Horizontally scrolling carousel
   - Image-backed cards with CTA buttons

7. **Call-To-Action (CTA) Section**
   - Primary and secondary CTA buttons
   - Supporting feature cards (Pricing & Quickstart)

8. **Footer**
   - Brand logo
   - Social media icons
   - Multi-column navigation links
   - System status badge
   - Theme toggle UI
   - Copyright section

- **Inter**

  - Clean, readable, and optimized for UI design

- **Geist Mono**
  - Used for small headings and labels
  - Adds a technical and modern feel
