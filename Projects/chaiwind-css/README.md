# Chaiwind CSS

A utility-first CSS-in-JS library inspired by Tailwind CSS.

## Usage

### Via CDN
```html
<script type="module" src="https://cdn.jsdelivr.net/npm/chaiwind/src/index.js"></script>
```

### Via npm
```bash
npm install chaiwind
```
```js
import 'chaiwind';
```

## Available Classes
- Spacing: `chai-p-1` to `chai-p-12`, `chai-m-1` to `chai-m-12`
- Typography: `chai-text-xl`, `chai-font-bold`, etc.
- Colors: `chai-bg-red`, `chai-text-blue`, etc.
- Layout: `chai-flex`, `chai-grid`, `chai-grid-cols-2`, etc.
- Borders: `chai-border`, `chai-rounded-lg`, etc.
- Shadows: `chai-shadow-md`, `chai-shadow-lg`, etc.
- Animations: `chai-animate-bounce`, `chai-animate-ping`, etc.
