How it works

Zero config. Just classes.

Drop in the script tag. Add utility classes to your HTML. Chaiwind scans the DOM and injects styles automatically.

01

Install

Add via npm or drop a CDN script tag into your HTML file.

npm i chaiwind-css
02

Import

Import once in your entry file or add the script tag to your HTML.

import 'chaiwind-css'
03

Use classes

Start adding chai- classes to any HTML element and watch it style up.

chai-flex chai-p-4
